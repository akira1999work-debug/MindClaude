# /slides — マインドマップからスライド生成

> MindClaudeのマインドマップデータを受け取り、Claude Codeがスライドを生成するスキル。

## 入力フォーマット

ユーザーが貼り付けるテキスト:

```
/slides
形式: [HTML|PPTX|PDF]
```json
{ "version": 1, "title": "...", "nodes": { ... }, "rootId": "root" }
```
```

- `形式` が省略された場合は `HTML` をデフォルトとする
- JSONがない場合は「マインドマップのJSONを貼り付けてください」と促す

## スライド構成ルール

### 基本方針
- ルートノード → タイトルスライド
- 深さ1の子ノード → 各スライドのタイトル（1子ノード = 1スライド）
- 深さ2以降 → スライド内のバレットポイント

### 最適化（Claude Codeの判断で実施）
- **類似ノードのマージ**: 内容が重複・類似するノードは1スライドにまとめる
- **冗長な削除**: 情報量の少ないノード（「その他」「備考」等で中身が薄い）は省略可
- **順序の最適化**: ストーリーの流れとして自然な順序に並べ替える
- **文言の改善**: ノードのラベルをスライド向けに簡潔に言い換える

### スライドデザイン
- シンプル、ミニマル、見やすさ重視
- 1スライドの情報量は少なく（バレットポイント3-5個まで）
- 日本語テキスト前提のフォント設定

## 出力形式別の生成方法

### HTML（デフォルト）

自己完結型の単一HTMLファイルを生成する:
- CSS/JS埋め込み（外部依存なし）
- 矢印キー / クリックでスライド遷移
- プログレスバー表示
- レスポンシブ対応
- 出力先: `C:\ClaudeCode\temp\slides\{タイトル}.html`

### PPTX

python-pptxを使った生成スクリプトを作成・実行する:
1. python-pptxがインストールされているか確認（なければ `pip install python-pptx`）
2. 生成スクリプトを作成して実行
3. 出力先: `C:\ClaudeCode\temp\slides\{タイトル}.pptx`

### PDF

HTMLを生成した上で:
1. HTML版を先に生成
2. ユーザーにブラウザで開いて印刷（PDF保存）を案内
3. または wkhtmltopdf / playwright が利用可能なら自動変換

## ワークフロー

### Step 1: 構造分析
マインドマップのJSONを読み、ノード構造を把握する。

### Step 2: 構成提案
以下をユーザーに提示する:
```
スライド構成案:
1. [タイトル] — タイトルスライド
2. [子ノード1のラベル] — バレットポイント: ...
3. [子ノード2のラベル] — バレットポイント: ...
...
合計: Nスライド

※ 以下のノードはマージ/省略しました:
- 「ノードA」と「ノードB」→ 1スライドにマージ（理由: 内容が重複）
- 「ノードC」→ 省略（理由: 情報量が少ない）

この構成で生成しますか？ 修正があれば指示してください。
```

### Step 3: ユーザー確認
- OKなら生成に進む
- 修正指示があれば構成を修正して再提案

### Step 4: スライド生成
指定形式でファイルを生成し、パスを通知する。

### Step 5: レビュー・修正
- ユーザーがスライドを確認
- 修正依頼があれば対応（文言変更、順序変更、スライド追加/削除）
- 修正は何度でも対応可

## NOTEの活用

ノードにNOTEがある場合:
- NOTE内容はスライドの補足説明・スピーカーノートとして活用
- PPTX: スピーカーノート欄に配置
- HTML: プレゼンモードでのみ表示されるノート欄

## 壁打ちモード

JSONなしで `/slides` が呼ばれた場合。テキスト素材の有無で分岐する。

### A. テキスト素材あり（メモ、議事録、箇条書き等が貼られた場合）
1. テキストを分析し、スライドに適した構造を抽出
2. マインドマップ構造のJSONに変換
3. 構成案をユーザーに提示（Step 2と同じフォーマット）
4. 確認後、MindClaudeに保存（POST /api/maps）して可視化を提案
5. スライド生成に進む

### B. テキスト素材なし（テーマだけ、またはゼロから）
1. テーマを聞く
2. 対話でアイデアを引き出す
3. マインドマップ構造のJSONを生成
4. MindClaudeに保存（POST /api/maps）して可視化を提案
5. 構成が固まったらスライド生成に進む

いずれの場合もマインドマップJSON化を経由することで、MindClaudeで可視化・編集→再度スライド化のサイクルが回せる。
